Kits y soluciones

Estos kits pueden enviarse a WhatsApp como base para una cotización rápida.

Kit base

Kit Inicial Residencial

Solución orientada a iluminación, consumos básicos y respaldo parcial.

  • Paneles solares de entrada.
  • Inversor básico según demanda.
  • Posibilidad de expansión.
Kit medio

Kit Residencial 5kW

Ideal para vivienda con refrigerador, iluminación, TV y electrodomésticos habituales.

  • Mejor equilibrio entre ahorro y autonomía.
  • Compatible con baterías.
  • Escalable por etapa.
Alta demanda

Kit Autonomía Total

Pensado para mayor consumo, respaldo extendido y opción de apoyo eólico.

  • Mayor capacidad fotovoltaica.
  • Respaldo con baterías.
  • Escenario híbrido completo.

  • El resumen se envía a WhatsApp con el pedido completo.
